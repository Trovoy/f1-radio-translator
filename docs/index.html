Built for race day

Keep your attention on the race.

Control the capture region, provider and viewing window. Common controls stay within reach.

01 / CAPTURE

See what you capture

Eight resize handles, position/size labels and keyboard nudges help define the region. The thumbnail refreshes every ten seconds and opens a larger preview. Save or clear the selection locally.

02 / READ

Read both languages

Compare Chinese translations with each English line and locally detected speaker labels. Switch to compact mode for a reading-focused window. The app interface is currently Chinese.

03 / TRANSLATE

Choose your provider

Use MyMemory, DeepL or an OpenAI-compatible endpoint. Supported prompts add F1 context. The GPT option requests gpt-6-luna; your upstream must support that model name or alias.

04 / CONTROL

Pause and stop separately

Resume after a pause or start again after stopping. Tray controls restore the window, control translation and exit. The window X exits and cleans up workers.

05 / REMEMBER

Reuse your local setup

Remember the region, provider and endpoint locally. Optionally encrypt saved keys for the current Windows user; reveal or hide them to check the input.

06 / DESKTOP

Built for a Windows window

A native dark WPF interface with slim scrollbars and manual compact mode. Persistent OCR, frame checks, deduplication and queuing reduce repeated work. Keep the latest 120 results.

Lights out in three steps

Three steps to read team radio.

01

Open the transcript

Open AI Radio Transcriptions in MultiViewer and make sure the English text is readable.

02

Select and verify

Include the transcript body and speaker line; check the thumbnail or enlarged preview.

03

Configure and translate

Enter the provider key and endpoint, then start. English originals and Chinese translations update as new lines are recognized.

Your machine, your settings

Screenshots stay local.
The source is open.

Screen capture and OCR run locally. Only recognized subtitle body text goes to your selected translation service; speaker labels are not appended. Keys and capture settings are not published with the source.
