# 隐私与本机数据

## 数据流向

```text
框选的屏幕区域
  → 内存中的截图
  → Windows 文字识别（本机）
  → 新出现的转录文字
  → 你选择的翻译服务，或显卡上的本地模型
  → 字幕窗
```

- 截图只在内存里处理，不上传，也不写入硬盘。
- 云端服务收到的是识别出的这一句文字；DeepL 和大模型还会收到同一车手的几句前文作为上下文，大模型还会收到说话人的名字。
- 使用内置本地模型时，翻译完全在本机完成，转录文字不会离开电脑。
- 文字识别可能出错；框选区域里的私人内容也可能被识别并当作转录文字发送出去。
- 请求使用你自己的密钥。软件没有共享密钥、作者代理服务器，也不收集任何统计数据。

## 网络访问

除了你配置的翻译服务，软件只会在你下载本地模型时访问 GitHub（llama.cpp 引擎）、魔搭社区和 Hugging Face（模型文件）。

## 本机保存的数据

| 数据 | 位置 |
| --- | --- |
| 设置：识别区域、服务顺序、字幕样式、窗口位置 | `%APPDATA%\com.trovoy.f1radio\settings.json` |
| API 密钥等敏感字段 | 同一文件，用当前 Windows 用户的 DPAPI 加密 |
| 本地引擎、模型、引擎日志 | `%LOCALAPPDATA%\com.trovoy.f1radio\local` |

Base URL 和模型名按普通设置保存，不要把密钥写进地址里。卸载软件不会删除这些文件夹，想清除全部数据请手动删除。

## 仓库内容

仓库包含源代码、图标、两张供文字识别测试用的转录截图（已去掉车手头像）和文档；不包含用户设置、真实密钥、DPAPI 密文、日志或个人路径。依赖、模型和编译产物都不进 Git。

## 反馈问题

请先隐去 API 密钥、授权请求头、账号信息、个人路径和带密钥的地址。不要在 Issue 里附上 `settings.json` 或 `.env` 文件。
